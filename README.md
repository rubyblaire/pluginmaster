# Ruby Blaire Plugin Repository

A grouped Dalamud experimental plugin repository for Ruby Blaire plugins.

## Installation

Copy this URL:

> https://raw.githubusercontent.com/rubyblaire/pluginmaster/main/pluginmaster.json

Then in Dalamud:

1. Open `/xlplugins`
2. Click **Settings**
3. Go to **Experimental**
4. Paste the URL into **Custom Plugin Repositories**
5. Click **Save**
6. Search for the plugin you want

*Please disable and delete the below plugins from their individual repos before using this collective.*

## Included Plugins

| Plugin | Description |
|---|---|
| **BoneSmith** | Native profile and template tools with a true smithing studio. |
| **SceneKeeper** | SFW RP scene tracking, partner tools, notes, and post drafting. |
| **Tyrian Targeting** | GW2-inspired manual targeting refinement for FFXIV. |
